# Go Live Checklist

Before you start processing any real payments, please make sure you have completed all the main steps below:

### 

**1\. Sandbox testing sign off**

Once you have completed testing in sandbox, our team will need to review and sign off before providing you with your live credentials. This can include a recording of your solution end-to-end or a 1:1 run through session with our engineering team with some completed sandbox transaction IDs for Bank and Mobile Money transactions.

### 

**2\. Product API key**

Once your sandbox testing is signed off, you're ready to receive your live credentials and be configured for production.

> 📘
> 
> ### 
> 
> API Keys permission
> 
> We have read / write permissions available on all API resources (receives, sends etc). You can ask to have your production key configured with specific permissions for better security. By default your production keys will be given all available permissions

> 🚧
> 
> ### 
> 
> IP Address whitelist
> 
> You'll need to provide us with your server's static IP address for whitelisting. Your API key will be deactivated if you make requests without whitelisting your server's IP address.

### 

**3\. Production Testing**

You have thoroughly tested your use case internally and with Yellow Card.

### 

**4\. Fund your account**

Top up your USD primary wallet balance with any USD Stablecoin so that you can start initiating sends and receives from your customers. You can top up your USD wallet balance directly on the Treasury Portal. [Read more about Balance top up](</docs/settlement-api#/>).

### 

**5\. Share your launch date**

When you are ready to launch, please share your go live date with us so that we can ensure adequate support to monitor the services.
